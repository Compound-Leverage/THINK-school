# Capture Team — Claude Code

## Overview

Discover, qualify, research, and prioritize opportunities; produce a decision-ready Capture Brief.

## Installation

Follow the [Claude Code marketplace instructions](../../../.claude-plugin/README.md). Confirm the plugin is available in your client before using it. A repository manifest alone does not confirm a successful installation.

## Configuration

Identify the organization explicitly. Supply only authorized organization information and sources. Provide organization criteria and inputs through the supported plugin configuration and session context. Do not assume live CRM access, procurement data, or permission to contact third parties.

## First assignment

> Use Capture Team for fictional Harborlight Systems. Find three fictional opportunities and label all invented details. Produce a Capture Brief with risks, unknowns, evidence gaps, and a Pursue / Investigate / Do Not Pursue recommendation. Stop for my approval.

## Expected deliverable

A sourced opportunity shortlist (or explicitly fictional practice data) and a Capture Brief with recommendation and next actions.

## Human approval and quality

The user confirms the opportunities and makes the pursuit decision. No CRM updates or external outreach without permission. Distinguish verified sources from assumptions and never fabricate citations.

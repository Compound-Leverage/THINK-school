# Proposal Team — Claude Code

## Overview

Research a qualified opportunity, assess bid fit, develop positioning, draft, and review a proposal with approval gates.

## Installation

Follow the [Claude Code marketplace instructions](../../../.claude-plugin/README.md). Confirm the plugin is available in your client before using it. A repository manifest alone does not confirm a successful installation.

## Configuration

Identify the organization explicitly. Supply only authorized organization information and sources. Provide organization criteria and inputs through the supported plugin configuration and session context. Do not assume live CRM access, procurement data, or permission to contact third parties.

## First assignment

> Use Proposal Team for fictional Harborlight Systems and a fictional opportunity. Label invented assumptions. Complete intake and Chase's preliminary research and Go/No-Go Discovery Brief, then stop for my approval before Priya or drafting.

## Expected deliverable

A Discovery Brief with preliminary fit, missing requirements, risks, and a recommendation for the human decision-maker. Subsequent approved stages may produce a proposal and QA report.

## Human approval and quality

Every stage has a human approval gate; no stage proceeds automatically when the user has not approved it. Distinguish verified sources from assumptions and never fabricate citations.

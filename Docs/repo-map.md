# Repository map

## User-facing navigation

| Area | Purpose |
|---|---|
| [Learn](../Learn/README.md) | Six work stages: Find, Qualify, Research, Capture, Respond, Review |
| [Marketplace](../Plugins/README.md) | Two installable Growth Team plugins: Capture and Proposal |
| [Skills](../Skills/README.md) | Standalone capabilities |
| [Docs](README.md) | Supporting architecture, methodology, and service guides |

## Technical directories

- `Plugins/`: Claude Code-native team packages.
- `openai-plugin/`: Codex-oriented execution packages; different skill structure.
- `.claude-plugin/` and `.agents/plugins/`: platform-required marketplace manifests; do not relocate for cosmetic navigation.
- `Agents/`: standalone methodology agents and expanded persona implementations.
- `Prompts/`, `Templates/`, `Workflows/`: historical and advanced reference files, preserved for compatibility. These are **not** the primary learner navigation.
- `Skills/`: standalone skill packages and source files, separate from plugin-internal execution skills.

## Learning model

Use [Learn](../Learn/README.md) to choose an assignment by the work to be done, then review the expected deliverable, human decision gate, and customization guidance. Some older reference material is named after Digital Employees; it does not require beginners to orchestrate individual personas.

Other team source packages are retained but are **not currently listed in the public marketplaces**.

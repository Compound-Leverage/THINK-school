# THINK School v1.1.0 — Release Notes

- Public catalog focused on Capture Team and Proposal Team, with platform-specific packages for Claude Code and OpenAI Codex.
- Direct installation from GitHub is independent of official marketplace approval.
- Six-stage learning path: Find, Qualify, Research, Capture, Respond, Review.

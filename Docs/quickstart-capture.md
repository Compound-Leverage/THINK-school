# Capture Team — first assignment (about one minute to start)

**Install:** Choose [Claude Code](../.claude-plugin/README.md) or [OpenAI Codex](../.agents/README.md). Installation differs by client; follow the platform instructions and confirm the plugin appears before proceeding.

**Configure:** Identify the organization explicitly. For OpenAI Codex, fill in the placeholders in [my-capture-config.json](../Plugins/OpenAI/capture-team/skills/capture-team/assets/my-capture-config.json) with your own capability and qualification criteria. Provide authorized sources and integrations only when available.

**Paste this assignment:**

> Use Capture Team for a fictional organization called Harborlight Systems, which provides IT modernization and data analytics to public-sector customers. Find three **fictional** opportunities, explicitly mark all invented details, then create a decision-ready Capture Brief for the strongest candidate. Show evidence gaps, risk, and a Pursue / Investigate / Do Not Pursue recommendation. Stop before any external outreach or CRM changes and request my approval.

**Review:** Check assumptions, evidence, fit, unknowns, and the human decision gate. See [illustrative Capture Brief](../Docs/samples/capture-brief.md). This sample is a format demonstration, not proof of live research.

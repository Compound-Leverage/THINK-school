# Find

**Managed Team:** Capture Team

Identify opportunities and demand signals.

## Assign work

> Find opportunities for [organization] using [sources] and [capabilities]. Return a sourced shortlist with deadlines, links, and unknowns.

Use real authorized organizational inputs or clearly labeled fictional data for practice. Never assume connected systems or permission to send anything.

## Review work

**Expected deliverable:** Opportunity shortlist with sources and deadlines.

**Human approval gate:** Confirm the opportunities are real and select which to qualify.

## Customize

Sources, capabilities, geography, scan cadence.

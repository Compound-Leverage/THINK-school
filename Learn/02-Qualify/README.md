# Qualify

**Managed Team:** Capture Team

Filter opportunities against explicit criteria.

## Assign work

> Qualify [shortlist] for [organization] against [eligibility, capabilities, capacity, priorities]. Show evidence, disqualifiers, and gaps. Do not invent scoring rules.

Use real authorized organizational inputs or clearly labeled fictional data for practice. Never assume connected systems or permission to send anything.

## Review work

**Expected deliverable:** Prioritized qualification report with rationale.

**Human approval gate:** Approve which opportunities warrant deeper research.

## Customize

Qualification rules, thresholds, CRM routing.

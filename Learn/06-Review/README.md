# Review

**Managed Team:** Proposal Team

Check quality before final delivery.

## Assign work

> Review [draft] against [solicitation]. Report coverage, consistency, compliance, unsupported claims, and issues with exact section references. Give PASS/WARNING/FAIL and recommended fixes. Do not submit.

Use real authorized organizational inputs or clearly labeled fictional data for practice. Never assume connected systems or permission to send anything.

## Review work

**Expected deliverable:** Traceable QA report and remediation checklist.

**Human approval gate:** Resolve critical findings and authorize delivery.

QA criteria, review depth, sign-off.

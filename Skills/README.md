# Standalone Skills

Reusable capabilities for learners who do not need an entire Managed Team. The current public Growth Team plugins are [Capture Team and Proposal Team](../Plugins/README.md); the [six-stage learning journey](../Learn/README.md) is the recommended starting point.

## Current skills

| Skill | Purpose | Source |
|---|---|---|
| THINK Foundations | Core THINK Method concepts | [SKILL.md](think-foundations/SKILL.md) |
| Signal Finder Toolkit | Opportunity and demand signal discovery | [Toolkit](Signal%20Finder%20Toolkit/README.md) |
| Community Grant Radar | Community funding opportunity research | [Skill package](community-grant-radar/community-grant-radar.skill) |
| Mandate Mapping | Map funding mandates and eligibility | [Guide](mandate-mapping/README.md) |

Skill support and installation differ by platform. Uploading a file into a chat may provide reference instructions, but **does not install a full marketplace plugin**. Follow the installation method supported by your chosen environment.

## Archived Digital Employee packages
